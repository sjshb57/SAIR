## 关于本项目

本项目基于 [Aefyr/SAI](https://github.com/Aefyr/SAI)。上游已停止维护，本仓库在其基础上持续更新：适配新版本 Android、修复长期存在的缺陷、重构项目结构。

## 导出的 .apks 元数据

SAI 会在导出的 `.apks` 文件中附加一些元信息，格式说明见 [META-FORMAT.md](META-FORMAT.md)。
